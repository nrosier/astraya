# src/astrology/ — Map

Pure astrological calculation (no DOM/React): bodies, aspects, houses, dignities, rulership, sect, Arabic parts, progressions, directions, returns, synastry, electional/horary/rectification, void-of-course, eclipses, fixed stars, harmonics, draconic, astrocartography. Every function is unit-testable without WASM/browser. Listed alphabetically.

- `almuten.ts` — Ibn Ezra's Almuten Figuris (essential-dignity scoring). Deps: `bodies`, `bounds`, `decans`, `rulership`, `sect`, `triplicity`.
- `antiscia.ts` — Antiscia/contra-antiscia ("hidden conjunctions") reflection + detection. Deps: `aspects`.
- `arabic-parts.ts` — Arabic/Hermetic lots (Part of Fortune/Spirit). Deps: `sect`.
- `aspects.ts` — Shared aspect-finding engine (Ptolemaic/minor, orbs, applying/separating). Deps: `bodies`.
- `aspect-patterns.ts` — Stellium, Grand Trine, T-Square, Grand Cross, Yod, Cradle, Mystic Rectangle from a chart's own aspects, per Astrolog 8.00 (#640). Deps: `./aspects`.
- `astrocartography.ts` — ACG + Local Space line calculation (MC/IC/AC/DC + great circles). Deps: `fixed-stars`.
- `ayanamsas.ts` — UI's sidereal-mode picker list. Deps: `ephemeris/generated-constants`.
- `bodies.ts` — Single source of truth: canonical body list (luminaries, planets, nodes, Lilith, Chiron, asteroids). Deps: `ephemeris/generated-constants`.
- `bounds.ts` — Egyptian + Ptolemaic "terms" tables. Deps: `bodies`, `signs`.
- `calculation-scheme.ts` — Named traditional scheme bundles (Hellenistic/Medieval Arabic/Renaissance-Lilly): bounds table + orb profile as one coherent choice (#549). Deps: `bounds`, `orb-profiles`.
- `decans.ts` — Decan/face rulership for essential-dignity. Deps: `bodies`, `dignities`, `signs`.
- `declinations.ts` — Equatorial contacts (parallels/contraparallels + out-of-bounds). Deps: ephemeris types only.
- `dignities.ts` — Base essential-dignity tables (rulership, exaltation, detriment, fall, traditional/modern). Deps: `bodies`, `signs`.
- `dispositors.ts` — Dispositor-chain + mutual-reception analysis. Deps: `rulership`, `signs`.
- `draconic.ts` — Draconic chart (re-measure from natal North Node). Deps: ephemeris types only.
- `eclipses.ts` — Eclipse search + natal-contact analysis. Deps: `bodies`, `ephemeris/types`.
- `electional.ts` — Electional astrology rule-scoring for auspicious timing. Deps: `aspects`, `bodies`, `emphasis`, `lunar-phase`, `void-of-course`.
- `emphasis.ts` — Chart balance (element/modality/quadrant/hemisphere/dominant body/sign/house). Deps: `dignities`, `signs`.
- `firdaria.ts` — Firdaria time-lord periods (seven classical planets + nodes, fixed years, day/night sect order) (#554). Deps: `sect`, `ephemeris/types`.
- `fixed-star-registry.ts` — Yemen fixed-star baseline table (al-Fārisī, c. 1270, as printed) + longitude helper. Deps: `signs`.
- `fixed-stars.ts` — Fixed-star conjunctions + paran (angle-crossing). Deps: `aspects`.
- `formula-parser.ts` — Safe recursive-descent arithmetic-expression parser/evaluator for user-defined points, no eval (#566). Deps: `ephemeris/types`.
- `harmonics.ts` — Harmonic charts (Western) + Vedic Varga/divisional (D1/D9/D10). Deps: `signs`.
- `horary.ts` — Horary "considerations before judgment" (radicality check via Lilly). Deps: `signs`.
- `houses.ts` — UI's house-system picker list. Deps: `ephemeris/types`.
- `jones-shapes.ts` — Marc Edmund Jones chart-shape classification (bundle/bowl/locomotive/etc.). Deps: `bodies`.
- `lunar-phase.ts` — Moon-phase name + waxing/waning + illumination. Deps: ephemeris types only.
- `lunations.ts` — Exact New/Full Moon instant finder, sample-then-bisect (#562). Deps: `bodies`, `ephemeris/types`.
- `midpoints.ts` — Midpoint astrology (near/far + 90-degree dial tree). Deps: ephemeris types only.
- `minor-progressions.ts` — Tertiary/minor progressions (day-for-lunar-month / lunar-month-for-year). Deps: `progressions`.
- `mutual-aspects.ts` — Planetary-cycle exact aspects (e.g. Jupiter-Saturn conjunctions). Deps: `aspects`.
- `nakshatras.ts` — Vedic nakshatra (lunar mansion) placement. Deps: ephemeris types only.
- `orb-profiles.ts` — Named/versioned orb presets over `aspects.ts`'s `OrbConfig`, the synastry scale offset, the per-context orb rule, and validation of per-aspect/per-body orb rules (#590). Deps: `aspects`, `bodies`, `transit-importance`.
- `orb-library.ts` — The device's named, revisioned orb profiles and each context's choice of orb source (card or a profile), pure and validated as a whole (#590). Deps: `orb-profiles`.
- `planetary-condition.ts` — Traditional condition (sect alignment, angularity, hayz, motion, besiegement) for the seven classical planets. Deps: `bodies`, `aspects`, `signs`, `sect`.
- `planetary-returns.ts` — Return search (any body), demibirthday, progressed-lunar-return. Deps: `minor-progressions`, `progressions`, `ephemeris/generated-constants`.
- `primary-directions.ts` — Primary directions engine (Placidus semi-arcs, in zodiaco at latitude 0, direct only; Naibod/Ptolemy keys). Deps: `aspects`, `progressions`.
- `profections.ts` — Annual/monthly profections (Hellenistic house-per-year). Deps: `signs`.
- `progressions.ts` — Secondary progressions (day-for-year, quotidian/naibod/solarArc MC). Deps: `ephemeris/types`.
- `reception.ts` — Essential-dignity reception across all five dignity types, including mutual and mixed reception (#548). Deps: `rulership`, `dignities`, `triplicity`, `bounds`, `decans`, `signs`, `sect`.
- `rectification.ts` — Birth-time rectification (score candidates by solar-arc/transit contacts). Deps: `bodies`, `progressions`.
- `rulership.ts` — Single place for "who rules this sign" (modern/traditional/both), essential dignities. Deps: `dignities`, `signs`.
- `sect.ts` — Sect (day/night) + Sun-proximity (oriental/occidental/cazimi/combust/under-beams). Deps: `aspects`.
- `sign-ingress.ts` — Exact sign-ingress instant finder, sample-then-bisect (#562). Deps: `signs`, `ephemeris/types`.
- `signs.ts` — 12 tropical signs (element/modality + sign-index/degree helpers). Deps: ephemeris types only.
- `solar-arc-directions.ts` — Solar arc directions (shift all bodies by progressed Sun's arc). Deps: `aspects`, `bodies`, `progressions`.
- `solar-lunar-returns.ts` — Solar + lunar returns (via ephemeris root-finders). Deps: `ephemeris/types`.
- `stations.ts` — Retrograde/direct station timing (longitude speed crosses zero). Deps: `ephemeris/types`.
- `synastry-importance.ts` — Synastry aspect ranking (body weight + aspect weight + orb closeness). Deps: `aspects`, `bodies`.
- `transit-events.ts` — Exact transit-to-natal aspect timing (via sample-then-bisect). Deps: `aspects`.
- `transit-importance.ts` — Transit filtering + ranking engine (daily/yearly presets). Deps: `aspects`, `bodies`, `rulership`.
- `triplicity.ts` — Triplicity rulership (Dorothean/Lilly, day/night/participating). Deps: `bodies`, `signs`.
- `void-of-course.ts` — Void-of-course Moon (last exact aspect before leaving sign). Deps: `aspects`, `bodies`.
- `zodiacal-releasing.ts` — Zodiacal releasing Levels 1–2 with Valens’ sign periods and Level-2 loosing-of-the-bond jump (#554). Deps: `dignities`, `signs`, `ephemeris/types`.
