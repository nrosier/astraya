# src/domain/ — Map

One level above `src/astrology/`: composes pure astrological calculations into shapes screens render. Still pure/async, no DOM/React.

- `angle-transits.ts` — Slow transits to the natal Ascendant and MC with orb, motion and exact dates, unscored (#678). Deps: `astrology/transit-events`, `astrology/transit-importance`.
- `aaf.ts` — AAF'97 birth-record format: encodes and decodes #A93/#B93 plus #SRC/#VIA/#COM and an extension in a #: chunk (#591). Deps: `time/types`.
- `aaf-people.ts` — Maps people to and from AAF records and stages an AAF import as a reviewed restore (#591). Deps: `./aaf`, `./person`, `./full-export`.
- `astrocartography.ts` — Astrocartography lines (MC/IC/AC/DC) + Local Space + relocated houses. Deps: `astrology/astrocartography`, `ephemeris/types`.
- `calculation-artifact.ts` — Completed calculation (natal, or a transit/synastry/primary-directions technique on it) as inputs + execution and time-resolution provenance + SHA-256 input/result fingerprints, and verification by recomputation (#582). Deps: `./calculation-snapshot`, `./chart-compute`, `./transit`, `./synastry`, `./primary-directions`, `ephemeris/assets`, `time/resolve`.
- `calculation-snapshot.ts` — Versioned calculation snapshot (settings, rulership, custom points, chosen fixed stars capped for share links, #860) with validated parsing, a strict all-fields settings decoder for person registers (#806) and a short provenance tag. Deps: `chart/extended-settings`, `astrology/rulership`, `./person`, `ephemeris/star-catalogue`, `store/ops` (JsonValue).
- `calculation-settings-migration.ts` — One-time staging of the device's chart settings, and then its ruler choice, onto existing people lacking their own (#806). Deps: `./person`, `store/oplog`.
- `chart-compute.ts` — Single source of truth: "what is in this chart" (positions, houses, aspects, dignities, sect, Arabic parts, declinations, fixed stars: the seven-star preset or the person's chosen ones, #803; opt-in Pholus via `includePholus`, #804). Deps: `astrology/aspects`, `astrology/rulership`, `astrology/arabic-parts`, `astrology/sect`, `astrology/bodies`.
- `chart-overview.ts` — One model of a chart's headline facts (big three, ruler, sect, balance, temperament, dispositor) for consultation, Report and PDF (#691). Deps: `astrology/emphasis`, `astrology/dispositors`, `astrology/rulership`, `./chart-compute`.
- `consultation-year.ts` — The year a consultation reads: profection and lord, firdaria, progressed Moon, solar returns (#669). Deps: `./profections`, `./secondary-progression`, `./solar-return`, `astrology/firdaria`, `astrology/lunar-phase`.
- `chart-share.ts` — Share chart via URL (no server round-trip). Encodes/decodes birth moment + settings as versioned query params. Deps: `time/encode`, `store/ops` (JsonValue).
- `degree-parts.ts` — Splits a longitude into sign/degree/minute/second; kept apart so eager `ui/format` avoids loading `chart-tables`. Deps: `astrology/signs`.
- `chart-tables.ts` — Converts chart data into UI table/wheel/sheet rows. Deps: `astrology/almuten`, `astrology/antiscia`, `astrology/declinations`, `astrology/dispositors`, `astrology/fixed-stars`, `astrology/jones-shapes`, `astrology/signs`, `./chart-compute`.
- `chart.ts` — Persisted "chart" entity (distinct from computed ChartData): person ref, kind, label, settings. Deps: `store/ops`, `./id`.
- `composite.ts` — Composite chart (synthetic midpoint + fresh aspect/dignity/sect/parts). Deps: `astrology/aspects`, `astrology/midpoints`, `astrology/rulership`, `astrology/sect`, `astrology/arabic-parts`, `./chart-compute`.
- `custom-point.ts` — Resolves/evaluates safe user formulas and detects duplicate built-in points (#566). Deps: `astrology/bodies`, `astrology/formula-parser`, `./chart-compute`.
- `demibirthday.ts` — Demibirthday timing (Sun opposes natal longitude each year). Deps: `astrology/aspects`, `astrology/planetary-returns`, `ephemeris/generated-constants`.
- `draconic.ts` — Draconic chart (lunar-node-based zodiac shift, same houses). Deps: `astrology/draconic`, `./chart-compute`.
- `event-search.ts` — Batch stations/ingresses/lunations/exact aspects plus reproducible CSV. Deps: `astrology/stations`, `astrology/sign-ingress`, `astrology/lunations`, `astrology/mutual-aspects`, `astrology/bodies`, `astrology/signs`, `time/julian`.
- `export-filename.ts` — Safe filename from person + chart kind. Deps: none (pure string).
- `full-export.ts` — Whole-device backup export (every person + computable natal/named-Varga tables + natal calculation artifact + CSV; also carries relocationPlaces/customPoints/fixedStars (#860) so a restore isn't lossy; each person's resolved calculation settings and rulership, v4, #806). Deps: `./chart-compute`, `./calculation-artifact`, `./harmonic`, `./chart-tables`, `./person`, `astrology/rulership`.
- `full-export-check.ts` — Verifies each person's recorded natal `CalculationArtifact` in a full-export file against what the current engine actually produces (verified/inconsistent/changed/no-artifact per person), without restoring or writing anything (#582). Deps: `./calculation-artifact`, `./full-export`, `ephemeris/types`.
- `full-export-importer.ts` — Validates an untrusted `FullExport` (strict format/version check; v4 export, v2-v4 accepted, v2/v3 people take the file's preferences as settings and rulership (#806); per-field validation reusing `person.ts`'s readers, rejects duplicate/reserved-name person ids) and stages a diff-based restore (new/updated/unchanged/deletedLocally per person) as `Mutation[]` (a person new to this device gets the default calculation profile for what their file lacks, #806), never touching computed chart fields or the `deleted` register (#587). Deps: `./full-export`, `./person`, `chart/extended-settings`, `time/types`, `store/oplog`, `store/ops`.
- `harmonic.ts` — Harmonic/Vedic Varga charts (D9 Navamsha, etc.). Deps: `astrology/harmonics`, `./chart-compute`.
- `horary.ts` — Horary chart, question-moment Julian day, considerations-before-judgment, and void-of-course check. Deps: `astrology/horary`, `astrology/void-of-course`, `astrology/emphasis`, `./chart-compute`.
- `horary-judgment.ts` — Horary significators, perfection/reception, prohibition, and relative-motion timing estimates (#552). Deps: `astrology/dignities`, `astrology/horary`, `astrology/reception`, `astrology/emphasis`, `./chart-compute`.
- `house-overlays.ts` — Synastry house overlays (which houses each person's bodies fall in, both directions). Deps: `astrology/emphasis`, `./synastry`, `./chart-compute`.
- `id.ts` — Local-first CSPRNG-backed prefixed base32 id generation (people/charts). Deps: Web Crypto API only.
- `lunar-returns.ts` — Lunar returns (every Moon-to-natal-longitude each cycle). Deps: `astrology/solar-lunar-returns`, `astrology/aspects`, `ephemeris/generated-constants`.
- `minor-progression.ts` — Tertiary/minor progressions (day-for-lunar-month / lunar-month-for-year). Deps: `astrology/minor-progressions`, `astrology/progressions`, `astrology/aspects`.
- `pdf-export-sections.ts` — PDF export builder content (selectable chart types/tables/sections + presets); view-only tables (`PDF_VIEW_TABLES`, `VIEW_TABLES`) that only a chart page's link adds, and `chartSectionForView` (#915). Deps: `ui/chart-sections` (ChartType, ChartViewKind).
- `periodic-transit.ts` — Periodic transit forecast (daily/weekly/monthly/yearly sky events). Deps: `astrology/transit-events`, `astrology/stations`, `astrology/aspects`, `./demibirthday`, `./lunar-returns`, `./progressed-lunar-return`, `./solar-return`, `./chart-compute`.
- `person-form.messages.ts` — i18n for birth-record form validation errors. Deps: none.
- `person-form.ts` — Birth-data entry form logic: Draft validation + minimal op-log mutations. Deps: `./person`, `./person-form.messages`, `time/types`, `store/oplog`, `store/ops`.
- `person-file.ts` — One person to and from a file (#699): reads AAF/Astraya JSON into people, stages replacing a person's birth data. Deps: `./aaf-people`, `./full-export-importer`.
- `person.ts` — Root entity: birth moment, named relocation places/formula points, per-person calculation settings and rulership registers with an unreadable flag (#806), chosen fixed stars read atomically (#803), place label, time accuracy, notes, offset witness. Deps: `time/types`, `astrology/formula-parser`, `./calculation-snapshot`, `chart/extended-settings`.
- `planetary-return.ts` — Any-body return chart (not just Sun/Moon). Deps: `astrology/planetary-returns`, `astrology/aspects`, `astrology/bodies`.
- `primary-directions.ts` — Lifetime direct/converse, zodiacal/in-mundo Placidus directions with configurable points and a mode-aware direct bi-wheel. Deps: `astrology/primary-directions`, `astrology/progressions`, `astrology/bodies`, `./chart-compute`.
- `primary-directions-settings.ts` — Pure comparison of a requested calculation snapshot against the locked Placidus/tropical settings primary directions use (#797). Deps: `./calculation-artifact`, `./calculation-snapshot`.
- `profections.ts` — Annual/monthly profections (Hellenistic house-per-year timing). Deps: `astrology/profections`, `astrology/rulership`, `astrology/progressions`, `astrology/signs`.
- `progressed-lunar-return.ts` — Progressed-lunar-return timing (monthly Solar-Return analogue). Deps: `astrology/planetary-returns`, `astrology/aspects`.
- `rectification.ts` — Birth-time rectification (ranks candidate times by life-event contacts). Deps: `astrology/rectification`, `time/julian`, `time/resolve`.
- `relationship-themes.ts` — Synastry relationship-summary themes (bond, attraction, communication, etc.). Deps: `astrology/aspects`, `astrology/bodies`, `./synastry`, `./chart-compute`.
- `relocated-chart.ts` — Relocated natal chart: same birth moment, different place, natal + relocated ChartData + a houses/angles comparison (#559). Deps: `./chart-compute`, `./chart-tables`, `time/julian`, `time/resolve`.
- `return-chart.ts` — Solar/lunar return as first-class displayable chart (with natal contacts). Deps: `./chart-compute`, `./lunar-returns`, `./solar-return`, `astrology/aspects`.
- `secondary-progression.ts` — Secondary progressions (day-for-year, three MC methods). Deps: `astrology/progressions`, `astrology/aspects`, `astrology/bodies`.
- `solar-arc-directions.ts` — Solar arc directions (apply progressed Sun's arc to all bodies). Deps: `astrology/solar-arc-directions`, `astrology/progressions`, `astrology/aspects`.
- `solar-return.ts` — Solar return (Sun returns to natal longitude each year). Deps: `astrology/solar-lunar-returns`, `astrology/aspects`, `ephemeris/generated-constants`.
- `synastry.ts` — Two-person compatibility core (independent charts + cross-chart aspects + importance ranking); applies synastry's tighter orbs to the orbs it is given. Deps: `astrology/aspects`, `astrology/orb-profiles`, `astrology/synastry-importance`, `./chart-compute`.
- `timing-timeline.ts` — Normalizes Level-1/2 time-lord periods and timing contacts/events onto one date axis (#554). Deps: `astrology/aspects`, `astrology/firdaria`, `astrology/transit-events`, `astrology/zodiacal-releasing`, `./profections`, `./primary-directions`, `./secondary-progression`, `./solar-arc-directions`, `./transit`, `./periodic-transit`.
- `transit.ts` — Transit bi-wheel (natal + moving positions + natal aspects); its contacts always include the three minor aspects its filter shows. Deps: `astrology/aspects`, `astrology/orb-profiles`, `./chart-compute`.
