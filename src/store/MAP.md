# src/store/ — Map

IndexedDB-backed op-log (local source of truth). HLC-ordered operations, folded into current state. "Spine" of synced ops frozen forever (ADR 0002).

- `account.ts` — Account preferences entity (#1066, ADR 0004): `account`/`preferences` fold to allowlisted per-field registers (and `orbProfile.<id>` per-profile orb registers, #1250), write guard refusing `deleted`/`purged`/other ids, adoption filter, sign-in reconcile state shape. Deps: `hlc`, `ops`, `oplog` (type).
- `db.ts` — IndexedDB persistence: schema/migrations, CRUD for op records, snapshot, device/sync metadata. Durability before UI success. Deps: ops, fold.
- `fold.ts` — Append-only log → people/charts/notes/saved queries/pins/account preferences/own corpus corrections (deterministic, byte-identical state on two devices). Last-write-wins field registers, note folding, materialization, snapshot. Deps: domain/chart, domain/person, account, chart-searches, corpus-corrections, hlc, notes, ops, pins, saved-queries.
- `hlc.ts` — Hybrid logical clock: causally-total timestamps across devices (encode/decode, tick, receive, device-id generation/validation, drift detection). Deps: none.
- `oplog.ts` — Append-only log: append mutations (and `appendAt` for seeds), merge peer records (duplicate/collision detection), slice for push, entity purge. Deps: hlc, ops, fold.
- `notes.ts` — Birth Record and Consultation notes as immutable revisions: head, forks, grow-only delete, legacy `person.notes` root, 50,000-character limit (shared predicate for import and sync; legacy over-limit kept local), held-back count, purge fan-out. Deps: `hlc`, `oplog` (type).
- `saved-queries.ts` — Saved event-search queries (#1061): fold to ready/unreadable/incomplete, write guard with the 500-character name cap, mutation builders, list order. Deps: `astrology/aspects`, `astrology/bodies`, `domain/id`, `interpretation/prompt-guardrail`, `notes` (type), `oplog` (type).
- `chart-searches.ts` — Saved chart searches (#1405): `chartSearch` entity (operator and conditions in one register, no as-of date), fold to ready/unreadable/incomplete, timing scopes (transit, progression, solar and lunar return) on schema version 2 with version 1 read as natal, write guard with the shared name cap and 10-condition limit, mutation builders, list order. Deps: `astrology/aspects`, `astrology/bodies`, `domain/id`, `saved-queries`, `notes` (type), `oplog` (type).
- `annotations.ts` — Annotations on pinned events (#1061): revision fold keyed by pin id (head and forks, via notes), write guard with the note limit, revision builder, the pointer an erase leaves on the pin (#1195). Deps: `domain/id`, `notes`, `oplog` (type).
- `corpus-corrections.ts` — A reader's own interpretation-text corrections (#1338): `corpusCorrection` entity per locale and key, fold, text validation, write guard (no purge), mutation builders. Deps: `interpretation/lint`, `interpretation/schema`, `notes` (type), `oplog` (type).
- `pins.ts` — Pinned event-search results (#1061): fold to ready/unreadable, derived-id identity, write guard, mutation builder, list order. Deps: `astrology/aspects`, `astrology/bodies`, `domain/event-search`, `domain/id`, `saved-queries`, `notes` (type), `oplog` (type).
- `ops.ts` — Operation envelope shape (disk/wire contract, forward-compatible decoding). Validates/decodes stored/incoming records (known/future/corrupt verdict), builds records, version-upcast machinery. Deps: hlc.
- `persist.ts` — Request storage persistence from browser, tri-state `PersistenceState`, user-facing warning copy. Deps: none.
- `store.ts` — Single live object for UI, concentrates impurity (db I/O, device-id, database name `dbName` (#919), notifications). Exports `mutate` (refuses invalid or oversized notes and reserved account writes and invalid corrections)/`seed` (minimum-HLC defaults that lose to any real write)/`remove`/`restore`/`purge` (person purge also erases notes; never for `account` or `corpusCorrection`)/`outgoing`/`receive` (ignores an account purge marker)/account reconcile meta/subscribe. Deps: db, fold, account, notes, oplog, hlc, ops, persist, tab-lock, trace.
- `tab-lock.ts` — Web Locks exclusivity per database (one writer, prevents HLC timestamp collisions across tabs). Fallback to always-writable. Deps: none.
